# AI小镇 · 数据说明（data.md）

> 版本 1.0 ｜ 2026-11-13 ｜ 依据 `docs/spcd.md` v1.2 §7.4、附录 B、附录 C
> 覆盖范围：`data/templates`（三套模板文案）与 `data/sample-town`（示例小镇）。字段约束以 `shared/contracts` 为准，本文只做说明，不构成第二事实源。

## 1. 文件清单

| 路径 | 内容 | 读取方 |
|---|---|---|
| `data/templates/index.json` | 三套模板的元信息（`id/name/summary/cover_hue/agent_count`） | 前端建镇页；`GET /v1/templates` |
| `data/templates/seaside.json` | 海边小镇完整模板 | 前端；`GET /v1/templates/seaside` |
| `data/templates/campus.json` | 大学城后街完整模板 | 前端；`GET /v1/templates/campus` |
| `data/templates/demolition.json` | 老城区拆迁楼完整模板 | 前端；`GET /v1/templates/demolition` |
| `data/sample-town/town.json` | 示例小镇的镇信息与 5 个居民 | 首页示例区 |
| `data/sample-town/reports/day-1.json` … `day-7.json` | 预渲染的 7 天小报 | 首页示例区 |

模板端点与前端静态加载共用同一批 JSON，只有一份事实源：端点不写库、不鉴权、不做缓存。

## 2. 模板结构

### 2.1 形状

```json
{
  "id": "seaside",
  "name": "海边小镇",
  "summary": "临海，人少，潮气重。留不住年轻人，也赶不走老人。",
  "cover_hue": 202,
  "agent_count": 5,
  "opening_scene": "雾从海面漫上来，六点，五金店的卷帘门先响了。",
  "agents": [
    {
      "name": "陈望",
      "age": 52,
      "occupation": "五金店老板",
      "persona": "丧偶三年，话少，每天六点开门，晚上一个人修收音机。",
      "secret": "他一直在等一封不会来的信，信封上是他老婆的字。",
      "conflict_goal": "想守着这家店，又怕守着的只是个空壳。",
      "speech_style": "短句。先答「嗯」，能用一个字不用两个字，很少主动开口。"
    }
  ]
}
```

### 2.2 字段约束

| 字段 | 类型 / 上限 | 说明 |
|---|---|---|
| `id` | 字符串，≤40 | 与文件名、索引一致；用于 `/v1/templates/{id}` |
| `name` | 字符串，≤40 | 模板名，模板内不要求跨模板唯一 |
| `summary` | 字符串，≤120 | 一句话世界观，建镇页展示 |
| `cover_hue` | 0–360 整数 | 封面色相，前端据此取色 |
| `agent_count` | 固定 5 | 与 `agents.length` 一致（C1） |
| `opening_scene` | 字符串，≤300 | 开场白，建镇后首次进入主界面展示 |
| `agents[].name` | 字符串，≤8 | 模板内唯一 |
| `agents[].age` | 1–120 整数 | — |
| `agents[].occupation` | 字符串，≤20 | — |
| `agents[].persona` | 字符串，≤300 | 外在设定，可被同镇居民看到 |
| `agents[].secret` | 字符串，≤200 | 只进入该居民自己的记忆与上下文，不得出现在他人上下文 |
| `agents[].conflict_goal` | 字符串，≤200 | 内在拉扯，驱动独白与冲突 |
| `agents[].speech_style` | 字符串，≤200 | 说话风格，用于对话生成时约束语气 |

**硬性规则**

1. 每套模板恰好 5 人（C1），不足或超出均返回 `E_VALIDATION`。
2. 同一模板内 `name` 不得重复。
3. 不得包含真实个人信息：手机号、邮箱、身份证号均会被 `validateTemplate` 拒绝。
4. 模板只读，不写入 IndexedDB，不随小镇数据导出。
5. 修改字段或新增必填项属于契约变更：必须先改 `docs/spcd.md` §7.4，再改实现与本文。

### 2.3 校验与读取

- 校验：`shared/contracts/template.js` 的 `validateTemplate` / `validateTemplateMeta`
- 端点：`GET /v1/templates`（列表）、`GET /v1/templates/{id}`（详情），见 [templates/index.js](../functions/templates/index.js)
- 用例：`npm run test:contract -- --grep "template"`（含 `templates-all` 三套齐全校验）

## 3. 三套模板

### 3.1 海边小镇（`seaside`，`cover_hue` 202）

- **一句话**：临海，人少，潮气重。留不住年轻人，也赶不走老人。
- **开场白**：雾从海面漫上来，六点，五金店的卷帘门先响了。
- **核心张力**：留下与离开。老一辈守着店与旧事，年轻人随时准备走。
- **公共空间**：五金店、咖啡店、码头。

| 居民 | 年龄 | 职业 |
|---|---|---|
| 陈望 | 52 | 五金店老板 |
| 林小满 | 24 | 咖啡店老板 |
| 周秀兰 | 61 | 退休教师 |
| 阿彪 | 35 | 货运司机 |
| 苗苗 | 9 | 小学生 |

**角色文案**

- **陈望**：丧偶三年，话少，每天六点开门，晚上一个人修收音机。
  - 秘密：他一直在等一封不会来的信，信封上是他老婆的字。
  - 冲突：想守着这家店，又怕守着的只是个空壳。
  - 说话：短句。先答「嗯」，能用一个字不用两个字，很少主动开口。
- **林小满**：从城里回来开店，热情，但总在算账。三个月没回本。
  - 秘密：她已经偷偷投了外地的工作简历，下周截止。
  - 冲突：想证明自己能行，又随时准备逃回去。
  - 说话：语速快，爱说「其实」，喜欢用反问句掩饰心虚。
- **周秀兰**：爱管闲事，在编一本小镇的口述史，见谁都问两句。
  - 秘密：她记录别人的故事，是为了不写自己的。
  - 冲突：想给镇子留下点什么，又怕写出来没人看。
  - 说话：书面语，爱说「我跟你说」，喜欢替别人下结论。
- **阿彪**：常年跑长途，回镇就喝酒，和妻子分居中。
  - 秘密：他跑车不是为了钱，是为了不在家。
  - 冲突：想回家，又怕回家。
  - 说话：糙话，爱笑，喝了酒话就多，喜欢拍别人肩膀。
- **苗苗**：周秀兰的孙女，放学后到处晃，是镇上唯一会直接说出真相的人。
  - 秘密：她把大人说的话都记在一个本子上，谁也不给看。
  - 冲突：想被当成大人，又希望有人管着她。
  - 说话：直接，问句多，常说「为什么」，不怕把话问到底。

**关系预设**：周秀兰与苗苗是祖孙；陈望与林小满是街上仅有的两家店；阿彪的货车是外部世界进出小镇的唯一通道。

### 3.2 大学城后街（`campus`，`cover_hue` 28）

- **一句话**：一条被学校围墙夹出来的街，白天卖饭，晚上卖安静。
- **开场白**：傍晚六点，后街的灯一盏盏亮起来，油烟顺着巷子往学校里飘。
- **核心张力**：考出去与留下来。所有人都把后街当临时落脚点，却一年年没走成。
- **公共空间**：打印店、面馆、便利店、出租屋。

| 居民 | 年龄 | 职业 |
|---|---|---|
| 赵一鸣 | 22 | 大三备考生 |
| 孙禹 | 26 | 便利店夜班 |
| 何蕾 | 30 | 打印店老板娘 |
| 老康 | 48 | 面馆老板 |
| 小唐 | 19 | 大一新生 |

**角色文案**

- **赵一鸣**：每天在打印店和自习室之间来回，书包里永远塞着一本没翻开的英语真题。
  - 秘密：他已经偷偷把考研志愿改成了本校，没敢告诉家里。
  - 冲突：想考上，又怕考上之后还是不知道自己想要什么。
  - 说话：说话爱用「就是说」，一紧张就重复上一句的结尾。
- **孙禹**：二战考研失败后留在后街，白天睡觉，夜里守着收银台。
  - 秘密：他把录取通知书的复印件贴在出租屋门后，每天出门都看一眼。
  - 冲突：想再来一年，又怕再来一年还是原地。
  - 说话：语速慢，常停顿，喜欢说「也行」，很少把话说死。
- **何蕾**：后街唯一一台彩色打印机的主人，见过太多人的论文和简历。
  - 秘密：她替学生打印过一封举报信，收件人正是她丈夫。
  - 冲突：想守住这家小店，又想离开这条街。
  - 说话：句子短，带点生意人的客气，结尾常加「行吧」。
- **老康**：在后街开了十五年面馆，记得每个常客的口味，不记得自己儿子的生日。
  - 秘密：他儿子三年前从他店里拿走了两万块，再没回来。
  - 冲突：想把店传给儿子，又拉不下脸打那个电话。
  - 说话：嗓门大，爱用「哎」开头，训人像在关心人。
- **小唐**：刚来两个月，白天上课，晚上在后街跑外卖，对什么都好奇。
  - 秘密：他谎报了年龄才注册上骑手账号。
  - 冲突：想快点长大，又舍不得被人照顾。
  - 说话：话密，爱问「真的假的」，喜欢把别人的话学一遍。

**关系预设**：打印店是何蕾与赵一鸣、孙禹的交汇点；面馆是老康的据点；小唐的送单路线串起整条街。

### 3.3 老城区拆迁楼（`demolition`，`cover_hue` 8）

- **一句话**：六层红砖楼，墙上写满「拆」字，楼道里还晾着衣服。
- **开场白**：早上七点，楼道里的声控灯坏了三天，搬家的人踩着纸箱下楼。
- **核心张力**：拆与留。有人已经签字，有人还在等一个说法，所有人都被同一栋楼绑在一起。
- **公共空间**：楼道、楼下折叠桌、顶楼水箱。

| 居民 | 年龄 | 职业 |
|---|---|---|
| 吴德海 | 64 | 退休纺织工 |
| 蒋秀英 | 58 | 楼长兼保洁 |
| 罗建军 | 41 | 拆迁办临时工 |
| 苏晴 | 27 | 租房设计师 |
| 牛牛 | 10 | 小学生 |

**角色文案**

- **吴德海**：在这栋楼住了四十年，每天把楼道扫一遍，谁家的事都记得。
  - 秘密：他签了拆迁协议，但一直没告诉楼里的老邻居。
  - 冲突：想拿钱搬走，又怕搬走以后没人记得这栋楼。
  - 说话：慢条斯理，爱说「想当年」，一激动就咳嗽。
- **蒋秀英**：负责整栋楼的钥匙和闲事，谁家漏水都先找她。
  - 秘密：她替吴德海瞒着签约的事，因为签字那天她在场。
  - 冲突：想把大家拧在一起，又知道自己拧不住。
  - 说话：语速快，爱说「我跟你说」，习惯替别人做决定。
- **罗建军**：本地人，被雇来劝邻居签字，每天在楼下支一张折叠桌。
  - 秘密：他家的房子也在拆迁范围里，他比谁都盼着早点签完。
  - 冲突：想保住这份工作，又不想被老街坊戳脊梁骨。
  - 说话：官话和土话混着说，爱用「按规定」，说完又补一句软话。
- **苏晴**：为了便宜租进这栋待拆的楼，把房间刷成了白色，像在给自己搭一个临时展台。
  - 秘密：她正在偷偷记录这栋楼，准备做成毕业作品。
  - 冲突：想留在城里，又不想承认自己随时会被赶走。
  - 说话：用词讲究，爱说「从设计上讲」，紧张时会笑一下。
- **牛牛**：在楼道里养了一只没人要的猫，放学就蹲在台阶上等搬家车。
  - 秘密：他把猫藏在了顶楼水箱后面，谁也没告诉。
  - 冲突：想让楼别拆，又知道拆了才能有新房子。
  - 说话：直接，问题多，常说「为什么」，不怕把大人问住。

**关系预设**：吴德海与蒋秀英共享同一个签字秘密；罗建军站在邻居的对立面，却有相同的利益；苏晴与牛牛是楼里唯二还在「记录」与「藏东西」的人。

## 4. 示例小镇

`data/sample-town` 由 `seaside` 模板预渲染，用于首页零成本展示（V8）。

### 4.1 `town.json`

```json
{
  "summary": "临海，人少，潮气重。留不住年轻人，也赶不走老人。",
  "town": {
    "id": "sample-seaside",
    "name": "海边小镇（示例）",
    "template_id": "seaside",
    "pace_mode": "quick",
    "status": "completed",
    "day_index": 7,
    "schema_version": "1.0.0"
  },
  "agents": [{ "id": "sample-seaside-chenwang", "name": "陈望", "age": 52, "occupation": "五金店老板", "persona": "…" }]
}
```

- `agents` 只保留展示所需字段（`id/name/age/occupation/persona`），不含 `secret/conflict_goal/speech_style`。
- `status=completed`、`day_index=7`：示例镇不可继续推进，只读浏览。
- 5 个居民与 `seaside` 模板同名同设定；模板文案改动时，示例镇必须同步。

### 4.2 `reports/day-N.json`

结构与 `shared/contracts/report.js` 一致：`town_id`、`day`、`headline`、`generation_mode`、`generated_at`、四类 `sections`（headline / scene / relation / unsaid）、5 条 `unsays`。

| 天 | 头条 | 生成模式 | 关系变化 |
|---|---|---|---|
| 1 | 码头起了雾，陈望和林小满站了一会儿 | normal | 陈望 ↔ 林小满：熟（0 → 3） |
| 2 | 周秀兰带着苗苗，从一楼问到六楼 | normal | 周秀兰 ↔ 苗苗：熟（0 → 3） |
| 3 | 阿彪的货车堵在五金店门口，两个人吵了两句 | backfill | 阿彪 ↔ 陈望：生（0 → -4） |
| 4 | 林小满收到一封邮件，在咖啡店坐了一下午 | normal | 林小满 ↔ 周秀兰：熟（0 → 3） |
| 5 | 苗苗把本子落在码头，陈望替她收了一个下午 | normal | 陈望 ↔ 苗苗：熟（0 → 3） |
| 6 | 录音笔不见了，楼道里谁都不承认见过 | degraded | 周秀兰 ↔ 阿彪：生（0 → -4） |
| 7 | 陈望修好了门口的信箱，五个人在码头站成一排 | normal | 陈望 ↔ 林小满、陈望 ↔ 苗苗：熟（3 → 6） |

三态（normal / backfill / degraded）均有覆盖，供页面区分展示与契约用例使用。

### 4.3 使用约定

- 首页启动即加载，断网可完整浏览 7 天，模型调用计数为 0。
- 示例数据不写入 IndexedDB，不参与用户小镇的推进、导出或分享。
- 分享长图可直接使用示例小报，不触发服务端出图。

## 5. 维护约定

1. **新增模板**：新增 `data/templates/{id}.json`，在 `index.json` 注册元信息，必要时接入 `functions/templates/index.js` 的静态导入；三处缺一不可。
2. **文案检查**：每套恰好 5 人、模板内不重名、无真实个人信息、`speech_style` 可区分、`secret` 与 `conflict_goal` 不重复。
3. **同步示例镇**：改动 `seaside` 的居民设定时，同步更新 `data/sample-town/town.json` 与相关小报，避免首页示例与模板不一致。
4. **验收命令**：
   - `npm run test:contract -- --grep "template"`：模板结构与三套齐全
   - `npm run test:contract -- --grep "report"`：示例小报结构与质量规则
   - `npm run test:e2e -- --grep "sample-town-offline"`：断网可看
